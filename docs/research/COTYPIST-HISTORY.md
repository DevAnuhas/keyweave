A version mention, a family heading and an independently dated release are not interchangeable.

The source/index sets reconcile to two feed items, two release headings, two enclosure versions and four explicit version identities. The public JSON contains original factual summaries, categories, source URLs/hashes and date qualifications, not copies of full vendor documents.
